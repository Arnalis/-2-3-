## Лабораторная работа №3. Нагрузочное тестирование

### Описание задачи

В рамках работы реализован инструмент нагрузочного тестирования на Python с использованием библиотек `threading` и `time`. 
Скрипт создает многопоточный генератор нагрузки, который имитирует запросы к целевой системе (сеть/БД), замеряет время отклика (Latency) и пропускную способность (TPS).

### реализовано

1) Эмуляция целевой системы с задержкой от 10 до 50 мс и 5% вероятностью ошибки
2) Многопоточная генерация нагрузки (виртуальные пользователи(воркеры))
3) Сбор метрик Latency и TPS
4) Механизм Ramp-up (ступенчатый запуск потоков с шагом 100 мс)
5) Расчет 95-го и 99-го перцентилей (P95 и P99) для оценки времени отклика
6) Замеры для 50 потоков и 500 потоков, где в выводе видно корреляцию между кол-вом потоков, временем выполнения и TPS. 

### Файлы

1) `load_test.py` — скрипт нагрузочного тестирования
2) 50 потоков.png - изображения формата png отображающее вывод результата нагрузочного тестирования для 50 поточной конфигурации;
3) 500 потоков.png - изображения формата png отображающее вывод результата нагрузочного тестирования для 500 поточной конфигурации 

### Запуск
